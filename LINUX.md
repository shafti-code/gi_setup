### Preface

Linux is known to work spotty across multitude of different distributions
thats why we will only be *offcially* supporting only a few distros including

Debian based distros using apt (ie. Ubuntu, Debian, Mint) and Fedora based distros using dnf however we reckomend using ubuntu based distros if dont already have a preference

### Before you start

to clone this repository you would need to have git installed 
and be logged into git cli with your github.com credentials
to log into git cli you need to install both git and github cli (named gh in most package manager repositories)
and enter the command 'gh auth login' and follow the instructions from the cli
this step is **required** to even clone the repository onto your computer in the first place


### Setup
1.Clone this repository onto your computer
``
git clone https://github.com/shafti-code/gi_setup
``
2. Run the linux_setup.sh script to install dependencies needed to run projects
